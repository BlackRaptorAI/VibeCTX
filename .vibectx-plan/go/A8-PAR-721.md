### Parser — five forms compiled and the emitted JavaScript read

| Source form | Runtime edge? |
|---|---|
| `import type { T } from "./d.js"` | **no** |
| `import { type T } from "./d.js"` | **no** |
| `import { type T, value } from "./d.js"` | **YES** — a mixed clause counts |
| `import { T } from "./d.js"`, `T` used **only** as a type | **no** — `tsc` elides it even with no `type` keyword |

`tsconfig.json` sets neither `verbatimModuleSyntax` nor `isolatedModules`. **Say all of this in the
test's own comment** — the next reader will not know.
